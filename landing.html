✨ Key Features

Everything needed to automate
your e-commerce catalog

A full end-to-end pipeline from data ingestion to live Shopify publication, powered by local AI.

👁️
Vision AI Pipeline
Automatically downloads product images and processes them through Llama 3.2 Vision via Ollama to extract colors, materials, style, and target audience — before generating copy.
llama3.2-visionOllamabase64
🔍
Hybrid RAG Search
Two-stage retrieval combining BM25 lexical search and pgvector cosine similarity fused via Reciprocal Rank Fusion (RRF). Followed by a CrossEncoder reranker for precision — no cloud vector DB needed.
BM25OkapipgvectorHNSWRRF
🤖
ReAct Agent — Function Calling
An autonomous AI Sales Agent powered by Gemini's native function calling. Uses a ReAct loop to search products, check stock, generate descriptions, with duplicate call detection to prevent infinite loops.
Gemini APIReActfunction_calling
⚡
Async Background Workers
Two independent asyncio queue pollers launched on FastAPI startup via asyncio.create_task(). One handles AI batch jobs, another manages Shopify API rate limits with exponential backoff.
asyncioFastAPI lifespanbackoff
📤
Excel / CSV Bulk Import
Drag-and-drop file upload that parses Excel (.xlsx) and CSV via pandas, validates every row (price, titles, image URLs), shows a live preview, and queues valid rows as ShopifyJob entries for AI enrichment.
pandasopenpyxlvalidation
🔗
Live Shopify Integration
A rate-limited Shopify Admin REST API client with semaphore concurrency control, exponential backoff on 429 errors, and full support for GET (fetch), PUT (update), and POST (create) operations.
Shopify APIhttpxrate-limit

# Hybrid BM25 + pgvector with RRF
async def hybrid_search(query, query_embedding):
    # BM25 lexical search
    bm25 = BM25Okapi(tokenized_chunks)
    bm25_scores = bm25.get_scores(query.lower().split())

    # pgvector cosine similarity via HNSW index
    vector_results = await chunk_vector_search(
        query_embedding=query_embedding, limit=candidate_limit
    )
    # Reciprocal Rank Fusion merge
    for cid in all_chunk_ids:
        bm25_rrf = bm25_weight * _rrf_score(bm25_rank[cid])
        vec_rrf  = vector_weight * _rrf_score(vector_rank[cid])
        rrf_scores[cid] = bm25_rrf + vec_rrf
    # CrossEncoder rerank top-20 to top-3
    return await rerank(query, candidates, top_k=3)

# Two async workers launched on startup
@asynccontextmanager
async def lifespan(_: FastAPI):
    # Bootstrap pgvector + tables
    async with engine.begin() as conn:
        await conn.execute(
            text("CREATE EXTENSION IF NOT EXISTS vector"))
        await conn.run_sync(Base.metadata.create_all)

    # Worker 1: AI description generator queue
    poller = asyncio.create_task(queue_poller())
    # Worker 2: Shopify API rate-limited push
    shopify = asyncio.create_task(shopify_queue_poller())

    yield  # App runs here
    poller.cancel()
    shopify.cancel()

        resp = await client.get(image_url, timeout=30.0)
        image_b64 = base64.b64encode(resp.content)

    # Send to Llama 3.2 Vision via Ollama
