How to Use — Quick Start Guide

Connect Your Store

Click Connect Shopify on the Optimizer page. The system fetches all products and identifies which ones need better descriptions.

Wait for AI Processing

Products are automatically queued. Vision AI reads the product image, then Llama-3 generates persuasive copy. No manual steps needed.

Review & Edit

Filter by Needs Review. Click any card to open the Interactive Editor. Use quick chips or write a Custom Request to refine the copy.

Approve & Push

When satisfied, click Approve & Push to Shopify. The updated description goes live on your store automatically via the Shopify API.

Batch Processing

Have hundreds of products? Use the Batch Pipeline tab. Paste a Google Sheets URL and the n8n workflow processes everything automatically.

AI Sales Assistant

The chat button (bottom-right) opens your AI assistant. It's context-aware — when a product is open, it gives tailored advice for that specific product.

Frequently Asked Questions
How does the AI generate descriptions?
The system uses a two-step pipeline. First, a Vision AI model analyzes the product image to detect colors, style, and visual features. Then a fine-tuned Llama-3 model generates a persuasive sales description. Everything runs locally — no cloud API costs.
What does each product status mean?
Pending — Found, waiting for processing.

Processing — Vision AI + Llama-3 are working.

Needs Review — Copy ready. Click to review & approve.

Done — Approved and live on your store.

Failed — An error occurred. Check the card for details and retry.
Can I edit the AI-generated text before publishing?
Yes. The text area in the Interactive Editor is fully editable. You can also use the quick-revision chips (SEO-Focused, More Energetic, etc.) or write a completely custom instruction using the Custom Request button. The AI will rewrite based on your exact instruction.
What is the Batch Pipeline and when should I use it?
The Batch Pipeline is for large catalogs. Put your product list in a Google Sheet, paste the URL, and an n8n workflow reads each row, sends it through Llama-3, and writes the copy back automatically. It's fully async — you can close your browser and check results later.
How do I use the Custom Request feature?
Open a product in the editor, click the Custom Request chip, and write your instruction in plain English — e.g. "Rewrite in a luxury tone, add 3 bullet points for key features, and include a call-to-action." Click Apply and the AI follows your instructions precisely.
Does approving a product immediately update my live store?
Yes. Clicking Approve & Push to Shopify calls the Shopify API and updates the product description in real-time. Changes are live within seconds. Ensure your Shopify credentials are correctly set in the backend environment variables.
What if a product fails processing?
Failed products show an error message on the card. Common causes: missing product image (Vision AI needs one), Shopify API rate limits, or the model server being unavailable. Open the editor and click Regenerate to re-queue the product.
